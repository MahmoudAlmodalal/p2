# محفظتي — منصة إدارة المحافظ والحسابات المالية

واجهة عربية RTL لمنصة خاصة لإدارة المحافظ والحسابات والحركات والتقارير المالية الشخصية والعائلية. المشروع يعرض تجربة تشغيلية متفاعلة مبنية حول الرصيد الموحّد، التدفق النقدي، دفتر الحركات، والتحويل بين عملتي ILS وUSD.

## ما هو موجود الآن

| المجال | ما تم تنفيذه في الواجهة |
|---|---|
| لوحة التحكم | صافي القيمة، السيولة، الادخار، المستحقات والالتزامات، مع مخطط زمني للأداء. |
| المحافظ والحسابات | عرض محافظ وحسابات ديناميكية مع الرصيد الحالي وحالة بصرية لكل عنصر. |
| دفتر الحركات | عرض الحركات، البحث ضمن الوصف والحساب، وإضافة دخل أو مصروف أو تحويل جديد في الذاكرة. |
| العملات والتقارير | تبديل عرض ILS/USD، ملخص تدفق نقدي، وتصدير CSV مطابق للحركات المرئية. |
| تجربة الاستخدام | واجهة عربية RTL متجاوبة تبدأ من 360px، وشريط جانبي دائم لسطح المكتب مع لوحة هاتف قابلة للفتح. |

## التشغيل المحلي

```bash
pnpm install
pnpm run dev
```

للتحقق من الأنواع والإنتاج:

```bash
pnpm run check
pnpm run build
```

## البنية الحالية وخطوة التكامل التالية

الواجهة مرتبطة الآن بواجهة Django REST عبر طبقة طلبات ذات جلسة آمنة (`credentials: include`) تستدعي مساحة العمل، الحسابات، المحافظ، الحركات، وصافي القيمة والتدفق النقدي من الخادم. ترحّل واجهة إضافة الحركة السجل عبر API ثم تعيد تحميل الأرصدة والتقارير من PostgreSQL.

يضبط المتغير `VITE_FINANCE_API_URL` على أصل API، مثل `https://api.example.com/api/v1` في الإنتاج أو `http://localhost:8000/api/v1` محلياً. ويتطلب استخدام التطبيق تسجيل الدخول في Django؛ لا تعتمد الواجهة على أي رصيد أو حركة وهمية بعد الربط.
